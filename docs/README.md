# DecodeBox documentation

Use the [workbench](https://decodebox.owasp.org/) to inspect data interactively, or embed the
same operations and analysis engine in an application.

- [Architecture](architecture.md) describes the workbench, worker, engine and runtime providers.
- [Development](development.md) covers local development, tests, builds and publishing.
- [JavaScript SDK](sdk/README.md) covers installation-free loading, distribution and versioning.
- [API reference](sdk/api-reference.md) documents inputs, options, results and failure handling.
- [Integrations](sdk/integrations.md) covers browsers, TypeScript, GraalJS and ZAP.
